# Security Policy

This project is a security-first blueprint. Vulnerability reports are welcome and taken seriously.

## Reporting a Vulnerability

Please report vulnerabilities privately using [GitHub Security Advisories](../../security/advisories/new) for this repository, rather than opening a public issue.

Include as much detail as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept
- The affected file(s) or workflow state(s)

You should expect an initial response within a few days. Please allow time for a fix to be developed and released before any public disclosure.

## Scope

This repository is an experimental reference implementation — see the [README](README.md) limitations section. It contains no live credentials, endpoints, or production integrations. Reports about the reference state machine, templates, and architecture docs are in scope; reports about how a _downstream implementation_ built from this blueprint might be deployed are out of scope for this repository.
